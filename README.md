# 📤 Сервис управления рассылками

Сервис для создания, отправки и мониторинга email-рассылок с поддержкой ролевой модели, подтверждения email, статистики и кеширования.

## 📌 Основные возможности

- ✅ **Управление клиентами**: добавление, редактирование, удаление (только своих)
- ✅ **Управление сообщениями**: создание шаблонов писем
- ✅ **Планирование рассылок**: задание времени начала и окончания
- ✅ **Отправка по требованию**: ручной запуск в разрешённом временном окне
- ✅ **Логирование попыток**: успешные/неуспешные отправки с деталями ошибок
- ✅ **Регистрация с подтверждением email**
- ✅ **Двухуровневая система ролей**:
  - **Пользователь**: работает только со своими данными
  - **Менеджер**: видит все данные, может блокировать пользователей и назначать менеджеров
- ✅ **Персонализированная статистика**: количество рассылок, успехов, ошибок
- ✅ **Кеширование**: повышение производительности через Redis
- ✅ **Восстановление пароля**

## 🛠 Технологии

- **Backend**: Python 3.10+, Django 5.2
- **База данных**: PostgreSQL
- **Кеширование**: Redis
- **Фронтенд**: Bootstrap 5, HTML, CSS
- **Аутентификация**: встроенная система Django + группы
- **Тестирование**: отсутствует

## 📦 Требования

- Python 3.10+
- PostgreSQL
- Redis (для кеширования)
- Poetry (для управления зависимостями)
